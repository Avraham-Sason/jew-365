## Bugs

- **On iOS the unencrypted taharah fallback file rides the iCloud device backup.** When the keychain cannot be read at launch, [TaharahStorage.ts](src/services/TaharahStorage.ts) opens `jew-365-taharah-unencrypted` in MMKV's default folder, `Documents/mmkv`, which iCloud backs up. The policy states it as it is (found 2026-10-14 while adding backup). Android is not affected: its backup whitelist leaves the file out. Fix: open that instance under `Library/Caches` (MMKV's `path`, never backed up; a purge only drops a fallback the encrypted file never relied on), or mark it excluded with `NSURLIsExcludedFromBackupKey` through a native module; then edit both policy pages.
